# 🔬 Digital Design Using FPGA - Labs

## 📌 Overview
This directory contains all the practical lab sessions, RTL designs, and testbenches completed during the **Digital Design Using FPGA** program at the National Telecommunication Institute (NTI). 

These labs represent a hands-on progression in digital hardware design, starting from basic combinational logic and advancing toward complex sequential systems and Finite State Machines (FSMs).

## 🎯 Learning Objectives & Topics Covered
The modules within this directory demonstrate proficiency in translating functional specifications into synthesis-ready hardware descriptions. Key topics include:
- **Combinational Logic:** Adders, Multiplexers, Decoders, and ALUs.
- **Sequential Logic:** D Flip-Flops, Shift Registers, and Synchronous/Asynchronous Counters.
- **Finite State Machines (FSMs):** Mealy and Moore machine implementations, including Overlapping and Non-overlapping Sequence Detectors.
- **Hardware Verification:** Developing robust testbenches to stimulate designs and verify expected behavior using waveforms.

## 🛠️ Tools & Technologies
- **Hardware Description Languages:** Verilog / SystemVerilog
- **Simulation & Verification:** QuestaSim / ModelSim
- **Synthesis & FPGA Flow:** Xilinx Vivado

## 🗂️ Lab Structure
*(Note: You can navigate to each specific lab folder for its individual source files and testbenches.)*
- Each lab directory typically includes:
  - `*_behavioral.v` / `*_structural.v`: The RTL design files.
  - `*_tb.v`: The simulation testbench.
  - Screenshots of waveform results (if applicable).

## 🚀 How to Run the Simulations
1. Navigate to the specific lab directory.
2. Launch your preferred simulator (**QuestaSim / ModelSim** or **Vivado**).
3. Compile the design module (`.v` or `.sv`) alongside its corresponding testbench file.
4. Run the simulation and observe the timing diagrams and console outputs to verify the logic.
